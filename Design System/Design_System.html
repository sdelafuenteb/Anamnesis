Retail Core

Tokens, tipografía y componentes extraídos de la presentación del roadmap. Está pensado para usarlo como base: copia los bloques de CSS y los fragmentos de HTML de cada componente. Soporta tema claro y oscuro.

Fundamentos

Principios

Reglas que se repiten en toda la presentación. Si algo nuevo las respeta, se verá como parte del mismo sistema.

1

Un solo azul de marca

El color de marca guía la mirada: números clave, encabezados de tabla, estado activo. El resto es neutro; el color extra solo comunica estado.

2

Color con significado

Verde es listo o ahora, azul es siguiente, amarillo es después, rojo es riesgo o brecha. Siempre acompañado de texto, nunca solo.

3

Números grandes, texto liviano

Rajdhani para cifras y títulos, DM Sans para leer. La jerarquía sale del tamaño y el peso, no de adornos.

Guía

Reglas de uso

Haz

  • Usa siempre variables (var(--brand)), nunca hex sueltos: así funciona el tema oscuro.
  • Acompaña el color con texto o forma; un estado no debe depender solo del tono.
  • Usa .stat para una cifra por idea, con etiqueta corta y una línea de contexto.
  • Mantén visible el foco: los controles usan outline: 3px solid var(--brand-2).
  • Reserva los números de fase (01, 02…) para secuencias reales.

Evita

  • Más de un color de acento por pantalla fuera de los semánticos.
  • Texto blanco fijo sobre colores sólidos: usa --on-solid o --on-brand, que se adaptan al modo oscuro.
  • Cards anidadas dentro de cards.
  • Sombras en componentes; solo el escenario y los popovers las llevan.
  • Animaciones decorativas: el movimiento responde a una acción o revela contenido.
